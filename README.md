손전등을 비추면서 햐안색으로 빛나는 곳들은 들어갈 수 있는 곳들입니다
퍼즐들은 비번맞추기,사슬,자물쇠 있습니다
비번은 0714이고 사슬은 그냥 많이 누르면 열립니다
